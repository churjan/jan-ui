## 用法

<div className="usage-code">

```tsx lineNumbers
import { CopyButton } from "@/components/jan-ui/copy-button"
```

```tsx lineNumbers
<CopyButton text="需要复制的内容" />
```

</div>

<Callout type="info" className="ps-3 [&>div[role=none]]:hidden">
  复制期间按钮暂时禁用；成功后显示勾选图标，失败后显示错误图标，可再次点击重试。成功和失败状态均在两秒后恢复，支持屏幕阅读器播报状态提示。
</Callout>

<Callout type="warn" className="ps-3 [&>div[role=none]]:hidden">
  剪贴板写入需要 HTTPS 或 localhost 环境及浏览器许可；不可用时会进入失败状态。
</Callout>

## 属性

<PropsTable rows={[
  { name: "text", type: "string", defaultValue: '""', description: "要写入剪贴板的文本，不传时复制空字符串。" },
  { name: "iconOnly", type: "boolean", defaultValue: "true", description: "默认仅显示图标，保留无障碍文案；设为 false 时显示文字。" },
  { name: "label", type: "string", defaultValue: '"复制"', description: "默认文案。" },
  { name: "copiedLabel", type: "string", defaultValue: '"已复制"', description: "复制成功文案，用于状态播报和悬停提示；文字模式下也显示在按钮中。" },
  { name: "disabled", type: "boolean", defaultValue: "false", description: "是否禁用按钮。" },
  { name: "className", type: "string", description: "附加样式类。" },
]} />

支持原生 button 属性（不含 children、onCopy、onError）和 ref。默认 `type="button"`，在 `onClick` 中调用 `preventDefault()` 可取消复制。
